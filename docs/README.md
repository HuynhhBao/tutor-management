# Tài liệu Dự án Quản lý Gia sư (Tutor Management)

Chào mừng bạn đến với tài liệu kỹ thuật của dự án Quản lý Gia sư. Tài liệu này được biên soạn nhằm giúp các nhà phát triển sau này có thể nắm bắt nhanh chóng cấu trúc và chức năng của hệ thống.

## 📌 Tổng quan dự án
Dự án là một hệ thống web cho phép người dùng tìm kiếm gia sư, đăng ký tài khoản, và quản trị viên quản lý danh sách gia sư.

## 📂 Danh mục tài liệu
1. [Xác thực & Bảo mật (Auth)](auth.md) - Đăng ký, đăng nhập, quên mật khẩu, phân quyền.
2. [Quản lý Gia sư](tutor-management.md) - Các chức năng CRUD cho gia sư.
3. [Quản lý Tài khoản Người dùng](user-profile.md) - Cập nhật thông tin cá nhân và đổi mật khẩu.
4. [Kiến trúc Backend](backend-architecture.md) - Cấu trúc code backend, database và mailer.
5. [Cấu trúc Frontend](frontend-structure.md) - Tổ chức source code frontend và các trang chính.

## 🚀 Công nghệ sử dụng
- **Frontend**: React.js, Vite, Tailwind CSS.
- **Backend**: Node.js, Express.js.
- **Database**: PostgreSQL.
- **Khác**: Docker, JWT, Bcrypt, Nodemailer.
